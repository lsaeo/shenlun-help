# 公考申论素材助手 V2

个人自用的申论备考素材软件：每日自动更新考公热点时事 + AI 生成考点分析，配合万能语段库、表达库、话题拆解框架与记忆复习系统，数据全部存本地 JSON。

## 功能

### 📰 今日热点（V2 重构）
- **权威源要闻抓取**：中国政府网 / 新华网 / 人民日报要闻区，不再使用会拉到旧闻的 RSS
- **14 天时效窗口**：旧闻自动丢弃，只留近 14 天内新闻
- **AI 挑重点**：从全量要闻中挑选最可能出题的 5 条，附理由 + 申论/行测适用标注（草稿审核后入库）
- **三层展示**：重点提炼 + 可背金句（大字号高亮）为主视图｜原文摘要折叠可展开｜角度/对策/可用方向齐全

### 🎴 话题卡
- 按主题轮转自动生成高频考点话题卡（背景/意义/问题/对策/金句/可用方向），草稿审核入库

### 📝 语段库
- 三维标签（功能位置 × 主题 × 手法）+ 全文搜索 + 一键复制 + 收藏
- 每条含**填空框架**（`____` 占位）与**改写例句**，可一键复制框架模板
- 每日从素材页搜集 + AI 改稿补全格式（草稿审核）

### 💬 表达库（V2 新增）
- 规范词（责任意识不足）/ 好词（共建共治共享）/ 平易词（钱袋子）单库多标签
- 搜索 / 按类型与主题筛选 / 收藏 / 一键复制

### 🗂 框架（V2 新增）
- **8 主题总览树**：民生/生态/法治/文化/创新/经济/基层治理/青年担当，聚合各主题下的表达/语段/热点/话题卡/案例
- **话题拆解树**：每个主题拆 3~6 个维度（如民生→养老/就业/教育/医疗），维度下挂素材
- **文章结构骨架**：开头/分论点/结尾三段式模板
- **AI 辅助拆解**：粘贴社会现象 → AI 拆出背景/问题/对策/可用方向 → 草稿审核入库

### 🔁 复习系统（V2 新增）
- 三库内容点「✔ 背完了」永久进入复习池，已入池/未入池分开显示，记住浏览进度
- 遗忘曲线排期（1/2/4/7/15 天…）+ 每日随机抽查
- 闪卡回忆式：先看标题回忆 → 展开 → 自评"记住了/模糊/忘了"推进或重置排期

### ⚙️ 设置
- API Key、每日更新时间与数量（热点/话题卡/语段/随机抽查）、启动补拉
- **字体可调**：基础字号与重点字号分开调节，实时生效

## 运行

```bash
pip install -r requirements.txt
python run.py
```

首次运行自动在 `data/` 初始化本地 JSON（种子来自 `seed/`）。

## 使用前必做

在应用「设置」页配置 AI 提供商（二选一）：
- **DeepSeek**：填写 API Key（默认模型 `deepseek-v4-flash`）
- **Google Gemini**：填写 Gemini API Key（Google AI Studio 免费申请，默认 `gemini-2.0-flash`）

不配置 Key 则 AI 生成不可用（热点分析/话题卡/范文解析），但本地内容（语段库/表达库/拆解树）可正常浏览。

## 目录结构

```
shenlun/
├── app/
│   ├── main.py        # PySide6 窗口 + 托盘 + 调度
│   ├── server.py      # FastAPI 本地服务 + API
│   ├── store.py       # JSON 数据层（含复习/拆解树/表达库集合）
│   ├── pipeline.py    # 每日流水线（抓取→AI 挑选→生成→审核流）
│   ├── fetchers.py    # 权威源要闻抓取（URL 日期校验 + 14 天窗口）
│   ├── llm.py         # DeepSeek 客户端（热点/话题卡/语段/拆解）
│   └── static/        # 前端（原生 HTML/JS，7 个 Tab）
├── seed/              # 种子内容（语段/话题卡/表达库/拆解树）
├── data/              # 运行时数据（备份=拷贝此目录，不入 git）
├── sucai/             # 机构参考 PDF（粉笔/中公，可选，不入 git）
├── docs/              # 方案文档
├── tests/             # 测试套件
└── run.py
```

## 开发流程（分支规范）

- `main`：**稳定发布分支**，只接受已完成验收的版本合并
- 功能开发在独立分支（如 `v2`），完成后经测试与验收再合并入 `main`
- 数据文件（`data/`、`sucai/`）与日志一律不提交
