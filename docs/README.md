- 新方案命名：`NN-<名称>.md`（NN 递增序号）。
- 每个方案开头标注：状态（草案/已确认/已废弃）、日期、依赖的上游方案。
- 实施偏离方案时，先在文档中修订并注明原因，再改代码。
