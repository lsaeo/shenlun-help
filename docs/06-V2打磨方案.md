# V2 打磨方案：表达库自动更新 + 范文模板化 + 拆解树可编辑 + 案例自动搜集 + 体验优化

- 状态：**已确认（2026-08-27 拷问定稿）**
- 依赖：[04-V2方案](04-V2方案.md)、[05-V2实施记录](05-V2实施记录.md)
- 目标：解决 v2 打磨的 6 个问题（表达库不更新、骨架死板、拆解树写死、跳转定位失败、案例库为空、范文未实现）+ 1 个体验问题（背完重排）

---

## 一、问题与方案总览

| # | 问题 | 方案 |
|---|---|---|
| 1 | 表达库不自动更新 | **每日网络搜集 + AI 提炼**：独立表达素材源 → AI 提炼规范词/好词/平易词 → 草稿审核 |
| 2 | 框架骨架死板 | **优秀范文 → AI 解析成结构化模板**：结构骨架 + 每段写法 + 可套用句式，存可编辑模板 |
| 3 | 拆解树写死 | **框架栏内可编辑**：增删改维度 + 每维度挂解释/使用案例，保存本地 JSON |
| 4 | 跳转表达库看不到 | **双向跳转 + 定位**：框架栏点词 → 表达库自动清筛选并定位高亮该词 |
| 5 | 案例库为空 | **每日搜集 + AI 拆解**：从素材页抓社会现象 → AI 拆背景/问题/对策/可用方向 → 草稿审核 |
| 6 | sucai 范文没做 | **范文自动抓取 + 3 选 1 审核流**：必应搜索聚合 → 3 篇候选 → 你选 1 → 存 sucai + AI 解析成模板 |
| 7 | 背完还在原位 | **立即移除 + 顶部自动顶上** |

## 二、表达库自动更新（问题 1）

### 2.1 素材源（独立配置）

config.json 新增 `expr_sources`（独立于语段素材源）：
```json
"expr_sources": [
  {"name": "规范词素材页", "url": "..."},
  {"name": "申论好词素材页", "url": "..."}
]
```
默认收录：中公/华图等公开的"申论规范词/高频词"素材页（实施时实测可用源）。

### 2.2 流水线集成

每日流水线新增"表达搜集"步骤（与语段搜集并行）：
1. 抓取 `expr_sources` 页面正文 → 切分候选段落
2. 与库内现有表达去重（text 前缀匹配）
3. AI 提炼：从段落中提取规范词/好词/平易词，输出标准结构：
   ```json
   {"text": "责任意识不足", "kind": ["规范词"], "theme": ["基层治理"], "example": "例句"}
   ```
4. 进草稿，审核入库

每日条数可配（`daily_expressions`，默认 3，0=关闭）。

### 2.3 与框架栏联动（问题 4 一并解决）

- **框架栏 → 表达库**：点击表达词 → 跳到表达 Tab，**清除 kind/theme 筛选**，把该词填入搜索框，渲染后高亮定位该卡片（滚动到可视区）。
- **表达库 → 框架栏**：表达卡片上的主题标签可点击 → 跳转框架栏对应主题（已实现，保留）。
- 前端 API：`/api/expressions/filter?q=词` 返回后按 text 精确匹配定位。

## 三、范文模板化（问题 2 + 6）

### 3.1 范文自动抓取（sucai/）

- **源**：必应搜索聚合（实测可用，百度反爬弃用）。搜索词如"申论 优秀范文 结构解析"。
- **流程**：
  1. 按配置节奏（默认每 3 天，config `fanwen_interval_days`）到点触发，或设置页手动"抓取范文候选"
  2. 抓搜索结果 → 取前 3 篇候选（标题+链接）→ 尝试抓正文（多源适配：华图/中公/其他公开站点；反爬源自动跳过换下一篇）
  3. 正文存入 `sucai/范文/YYYY-MM-DD/` 目录（候选 3 篇全存，待选）
  4. 应用内"范文待审核"区展示 3 篇候选（标题+正文预览）
  5. **你选 1 篇确认** → 其余丢弃（可选保留）
- 未确认前候选不删除，可随时回看。

### 3.2 AI 解析成结构化模板（问题 2）

确认范文后，AI 自动解析输出：
```json
{
  "title": "范文标题", "source": "来源", "date": "确认日期",
  "theme": ["适用主题"],
  "structure": [
    {"part": "开头", "role": "亮明观点", "how": "引用金句+点题", "pattern": "可套用句式", "excerpt": "原文对应段落摘录"}
  ],
  "killer_sentences": ["全文可背金句1", "金句2"]
}
```
- 存 `data/templates.json`（新增集合），框架栏"骨架"区展示为**可编辑模板卡**（可改/删/新增）。
- 保留原文对照：模板卡关联 sucai/ 下的原文文件。

### 3.3 骨架区改造

- 现有写死的三段式说明 → 替换为模板库列表（可编辑）。
- 未解析模板时保留一段默认说明兜底。

## 四、拆解树可编辑（问题 3）

- 框架栏主题区加"**编辑拆解**"按钮 → 弹窗内：
  - 增/删/改维度名称
  - 每维度可编辑 `items`（素材标签列表）
  - 每维度新增 `explain`（解释：这个维度指什么、为什么考）+ `cases`（使用案例：真题/作答示范）
- 保存走既有 `PUT /api/topics/{theme}`。
- 维度详情：点击维度展开查看 explain + cases + 关联素材（前端展开交互）。

---

## 五、案例库自动搜集（问题 5）

- 每日流水线新增"案例搜集"步骤：
  1. 抓取素材页（复用 `phrase_sources`，社会现象/治理案例类内容）
  2. AI 拆解为标准案例结构（背景/问题/对策/可用方向/主题）——复用 `decompose_case` 的 LLM 能力
  3. 去重（title/背景相似度）+ 进草稿审核
- 每日条数 `daily_cases`（默认 2，0=关闭）。
- 种子：起草 5~8 个典型案例（社区治理/垃圾分类/数字鸿沟等）作起步内容。

## 六、背完重排（问题 7）

- 前端点"背完了"后：
  1. 调 `/api/review/{type}/{id}/add`（已有）
  2. **当前列表内该卡片立即移除**（DOM 删除），若列表为空显示空态
  3. 下一个卡片自然上移，无需滚动
- 已入池标记仍在卡片上（刷新后可见"已入复习池"），但当前会话内已移除的卡片不再显示"背完了"按钮干扰。

## 七、涉及改动清单

| 模块 | 改动 |
|---|---|
| `app/store.py` | config 加 `expr_sources`/`daily_expressions`/`daily_cases`/`fanwen_interval_days`；新增 templates.json 集合（模板 CRUD） |
| `app/fetchers.py` | 新增 `fetch_fanwen_candidates`（必应搜索 + 正文抓取多源适配）；表达/案例素材页抓取（复用 fetch_phrase_source） |
| `app/llm.py` | 新增 `extract_expressions`（段落→规范词/好词/平易词）、`parse_fanwen_template`（范文→结构化模板） |
| `app/pipeline.py` | 每日新增：表达搜集、案例搜集；范文候选定时抓取（按 interval_days） |
| `app/server.py` | 新增 templates CRUD、范文候选/确认 API、表达定位 API（q 精确匹配返回索引） |
| `app/static/*` | 骨架区改模板卡（可编辑）；拆解编辑弹窗；维度展开详情；跳转定位+高亮；背完移除重排；范文审核区；设置页新字段 |
| `seed/` | 案例种子 5~8 个；表达库补种子 |
| `tests/` | 新增表达提炼/模板解析/案例搜集测试；更新既有断言 |
| `.gitignore` | 确认 sucai/ 已忽略（已有） |

## 八、边界（本次不做）

- 不做范文正文的深度清洗（保留原文段落，模板由 AI 生成）
- 不做粉笔站内专抓（改版风险高，用搜索聚合）
- 不做自动确认范文（必须人工 3 选 1）
- 不做拆解树的跨主题拖拽排序（v2 内文本编辑足够）

## 九、验收标准

1. 每日流水线生成表达/案例草稿；表达库与框架栏双向跳转定位成功（清筛选+高亮）
2. 范文 3 选 1 审核流跑通：抓候选 → 确认 → AI 解析出结构化模板 → 骨架区显示可编辑模板
3. 拆解树可增删改维度、每维度可编辑解释与案例并保存
4. 案例库有种子 + 每日草稿
5. 点"背完了"卡片立即移除、列表自动上移
6. 全量回归通过
