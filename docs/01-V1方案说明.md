# 公考申论素材助手 V1 方案说明

- 状态：**已确认（2025-06 定稿）**
- 目录：本文件为 V1 的权威方案；实施过程中的任何偏离以本文件为基准，改动需更新本文件。

---

## 一、产品定义（一句话）

**一台电脑上自用的 Python 桌面应用**：每天自动抓真实新闻 + 调 DeepSeek 生成考点分析和话题卡 → 进"待审核" → 你审核入库；另有按"功能位置 × 主题 × 手法"三维组织的**万能语段库**，支持搜索、复制、收藏。数据全部存本地 JSON。

## 二、已确认的决策（三轮拷问汇总）

| 维度 | 结论 |
|---|---|
| 形态 | 桌面应用：Python 后端 + 内嵌浏览器 UI（PySide6 + QWebEngineView） |
| 模型 | DeepSeek/通义国内 API，按量付费（每天约 10 次调用，成本极低） |
| 热点来源 | 免费源抓取真实新闻 + AI 写考点分析 + AI 生成高频话题卡（两者都要） |
| 更新方式 | 应用常驻系统托盘，到点自动跑；启动时补拉错过的天数 |
| 质量闸门 | 草稿 → 人工审核 → 入库，AI 内容永不直接进库 |
| 语段组织 | 三维标签：功能位置（开头/结尾/过渡/论证）× 主题（民生/生态/法治/文化/创新/经济/基层治理/青年担当）× 手法（排比/对仗/引用/比喻/设问/递进） |
| v1 功能 | 浏览 + 全文搜索 + 标签组合筛选 + 一键复制 + 收藏 |
| 每日产量 | 5 条真实热点分析 + 5 张话题卡（审核约 5~10 分钟） |
| 运行方式 | 开发期 `python` 直接跑，exe 打包留到以后 |

## 三、架构

```
PySide6 窗口
 ├─ QSystemTrayIcon 托盘（打开主界面 / 立即生成今日 / 退出）
 ├─ QWebEngineView 内嵌浏览器 ←→ http://127.0.0.1:随机端口
 │                                    └─ FastAPI 本地服务
 │                                        ├─ /api/* JSON CRUD（读写 JSON 文件）
 │                                        └─ 静态托管前端（原生 HTML/JS，无构建）
 └─ 调度器（QTimer 驱动）
     └─ 每日流水线：抓取 → 调 DeepSeek → 写草稿 → 托盘通知审核
```

依赖：`PySide6`、`fastapi`、`uvicorn`、`httpx`、`beautifulsoup4`。前端零依赖零构建。

## 四、数据模型（全部本地 JSON，备份=拷贝文件夹）

`data/` 目录随应用存放：

- **hotspots.json**：`{id, date, title, source, url, summary, 意义, 角度, 对策, 金句, status: 草稿|已入库}`（summary 为纯文本，已剥除 HTML 标签）
- **topic_cards.json**：`{id, date, theme, topic, 背景, 意义, 问题, 对策, 金句, status}`
- **phrases.json**：`{id, text, template, examples[], position[], theme[], technique[], usage, collected, used_count}`——其中 `template` 为填空框架（具体内容以 `____` 占位），`examples` 为改写例句数组
- **config.json**：API key、更新时间（默认 07:00）、每日数量、新闻源列表、last_update_date

## 五、每日流水线（含遗留风险处置）

1. 到点触发。**已接受的坑**：托盘常驻意味着"关掉应用就不更新"——补偿机制是启动时检查 last_update_date，缺失 ≤3 天自动补拉（进草稿）。
2. 抓取免费源：v1 先接新华网/中国政府网 1~2 个源，源列表可在设置里扩展。**抓取的摘要会剥除 HTML 标签，只留纯文本。**
3. 抓取失败 → 降级：跳过真实热点只生成话题卡；"手动录入"兜底。
4. 调 DeepSeek 生成 5 条热点分析 + 5 张话题卡，全部标草稿。
5. 托盘通知"有 10 条待审核"，你逐条确认入库或删除。

**关于语段库**：语段库以**人工积累为主体**（种子 56 条 + 手动录入），并新增**每日网络搜集 + AI 改稿**增量机制（详见 [03-语段库每日搜集与AI改稿](03-语段库每日搜集与AI改稿.md)）：每天从配置的素材页抓取候选语段，AI 将缺填空框架/改写例句的素材改写成标准格式（text + template + examples + 三维标签 + usage），去重后进草稿审核。每条语段配套**填空框架**（挖空具体内容、保留句式骨架，用于套用）与**改写例句**（演示框架如何套用到其他主题）。

## 六、前端页面

- **今日热点**：按日期倒序，草稿/已入库筛选，审核按钮；字段标签（意义/角度/对策/金句）以加粗胶囊样式突出。
- **话题卡**：按主题筛选；字段标签突出可读。
- **语段库**：三维标签 + 关键词组合筛选；展示语段正文、填空框架、改写例句；一键复制正文或框架、收藏、可手改。
- **设置**：API key、更新时间、每日数量、新闻源管理。

## 七、种子内容（我负责起草第一批）

- 语段库 56 条，覆盖四类位置 × 全部主题 × 常见手法，每条带：适用场景 + **填空框架**（`____` 占位）+ **改写例句**（1~2 条）；
- 话题卡预置 ~10 张示例；
- 热点表空库起步（真实数据由每日流水线产生）。

## 八、里程碑

1. 骨架：PySide6 窗口 + 内嵌浏览器 + FastAPI + 托盘
2. 数据层：JSON 读写 + CRUD API
3. 前端：三页面 + 搜索/筛选/复制/收藏 + 录入/审核
4. 流水线：抓取 + AI 生成 + 草稿入库 + 定时 + 补拉
5. 种子内容起草
6. 全链路验收

## 九、已拍板的小事（均可改）

- 数据目录：应用根目录 `data/`；
- 默认更新时间 07:00、补拉上限 3 天、5+5 产量；
- 新闻源从新华网 RSS + 中国政府网开始；
- 模型默认 `deepseek-chat`。

## 十、V1 不做（边界）

写作编辑器、AI 批改、多设备同步、数据库、账号、exe 打包、手机端、自动归档。
