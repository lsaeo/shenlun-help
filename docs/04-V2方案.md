# V2 方案：热点质量重构 + 复习系统 + 框架栏/表达库 + 启发性改造 + 可调字体

- 状态：**已确认（2026-08-27 拷问定稿）｜已实施（2026-08-27）**
- 依赖：[01-V1方案说明](01-V1方案说明.md)、[02-V1实施记录](02-V1实施记录.md)、[03-语段库每日搜集与AI改稿](03-语段库每日搜集与AI改稿.md)
- 目标：解决用户使用中发现的 5 类问题（热点抓取质量、无复习机制、缺框架/词汇、素材缺启发性、字体过小）

> **实施指令（用户明确要求）**：v2 上线时**先将热点库清空（删除全部热点，含已入库），再从新抓取/挑选流程重新引入**，确保库里无旧数据残留。✅ 已执行：2026-08-27 清空后由新流水线重新生成 5 条三层结构热点草稿。

---

## 一、问题与根因（已实测确认）

| 用户问题 | 根因 |
|---|---|
| 拉到 2020/2022 年旧闻 | 人民网 RSS 为死源（100 条全是 2025-06-05 静态缓存）；新华网 RSS pubDate 不可信（聚合页把旧专题盖成当天日期） |
| 拉不到重点新闻 | 关键词过滤只匹配标题，真正重点新闻（如领导人外事活动）标题不含关键词被过滤；匹配关键词的旧专题反而入选 |
| 大段摘抄、没画重点 | summary 整段灌入，AI 只输出四个固定字段，无"重点提炼/可背金句"输出，前端无高亮 |
| 无复习机制 | 三库只有浏览/审核，无记忆排期、无进度记忆 |
| 缺框架栏/词汇 | 无申论主题总览、无文章结构骨架、无规范词/好词/平易词表达库 |
| 字体过小 | 全局 14px 固定，重点内容无区分 |

## 二、热点抓取重构

### 2.1 新闻源与时效

- **源**：废弃现有 RSS 直抓方案，改为**抓权威源"要闻区/头条区"列表页**（人民日报要闻、中国政府网要闻、新华网要闻），源头即重点；保留 RSS 作为补充。
- **时效**：抓取后校验发布日期，**仅保留近 14 天内**的新闻；14 天前一律丢弃。无匹配时提示"近 14 天无重点新闻，建议手动录入"。
- **不靠关键词过滤**：抓全量当日要闻 → 由 AI 挑选。

### 2.2 重点挑选（源头重点 + AI 挑拣并行）

1. 抓取权威源要闻区全量标题+摘要。
2. **AI 挑选**：从全量中选出最可能成为考公题目的 **5 条**（申论与行测均可涉及），输出理由：
   ```json
   {"pick": [{"title": "...", "summary": "...", "why": "为何适合考公", "candidate_subjects": ["申论-民生", "行测-常识"]}]}
   ```
3. 生成后进草稿，人工审核（保留既有审核流）。

### 2.3 机构参考（可选增强）

- 目录：`sucai/`（**git 忽略，不上传**），结构：`sucai/<下载日期>/粉笔<发布日期>.pdf`、`sucai/<下载日期>/中公<发布日期>.pdf`。
- 用户手动下载最新版 PDF 放入；应用扫描 `sucai/` 下 PDF，若存在则 AI 可读 PDF 提炼高频考点作为挑选参考信号；无 PDF 则跳过，不影响主流程。
- 有新版本时用户更新 PDF 即可（应用按目录名识别最新批次）。

### 2.4 展示重构（画重点）

每条热点展示改为三层：

| 层级 | 内容 | 默认状态 |
|---|---|---|
| 主视图 | AI **重点提炼**（3~5 条核心要点，每条一句话）+ **要点列表** + **可背金句** | 展开 |
| 折叠区 | 原文摘要（清洗后纯文本） | **收起**，点击展开 |
| 高亮 | 重点句/关键词加粗+底色 | 始终可见 |

AI 输出字段扩展：`重点提炼: [3~5条]`、`可背金句: string`（区别于现有"金句"——金句是分析金句，可背金句是可直接背诵的一句话），保留原有 `意义/角度/对策`。

## 三、复习系统

### 3.1 核心机制

- **显眼"背完了"按钮**：三库每条内容（热点/话题卡/语段）卡片上有醒目按钮（如"✔ 背完了"），点击后该条**永久进入复习池**。
- **入池/未入池分开显示**：列表提供"全部 / 已入复习池 / 未入复习池"筛选。
- **进度记忆**：记住上次浏览位置，重新打开不从头开始（本地记录每库的滚动位置/上次看到哪条）。

### 3.2 排期（遗忘曲线 + 随机抽查）

- 新入池内容按记忆曲线排期：第 1、2、4、7、15 天…到期复习。
- 每天"今日该复习"清单 = 曲线到期项 + 每日随机抽查 N 条（老内容防止遗忘，N 可配置）。
- 复习时：闪卡回忆式——先看标题/话题名/语段框架回忆，点开看全文，自评"记住了/模糊/忘了"。
  - 记住了 → 进入下一级间隔；
  - 模糊/忘了 → 重置到更短间隔，重新排期。

### 3.3 数据模型

`data/review.json`（新增）：
```json
{
  "items": [
    {"type": "hotspot|card|phrase", "item_id": "...", "stage": 0, "next_review": "2026-08-28",
     "last_review": "2026-08-27", "review_count": 1, "score": 3}
  ],
  "progress": {"hotspots_scroll": 1234, "cards_scroll": 0, "phrases_scroll": 567},
  "daily_random": 3
}
```
- 入池：点"背完了" → `review.json` 添加记录，stage=0。
- 到期判断：`next_review <= 今天` 且 `status != 已掌握`（连续多次记住可标记掌握，不再出现）。

## 四、框架栏 + 表达库

### 4.1 框架栏（新导航区，第五个 Tab"框架"）

**A. 主题总览树**（沿用 8 主题：民生/生态/法治/文化/创新/经济/基层治理/青年担当）：
- 每个主题节点下聚合展示：相关规范词、好词、平易词、语段、热点、话题卡（按 theme 标签关联）。
- 作用：写申论时按主题一站找齐素材。

**B. 文章结构骨架**：
- 开头 / 分论点 / 结尾 三段式骨架模板（每位置含可套用句式，关联语段库的 position 标签）。
- 独立页面展示"万能骨架"与各位置素材。

### 4.2 表达库（新库，第六个 Tab"表达"）

- 单库多标签，每条：
  ```json
  {"text": "责任意识不足", "kind": ["规范词"], "theme": ["基层治理"], "example": "例句", "level": "规范|亮点|平易"}
  ```
- `kind` 三选一或多选：**规范词**（责任意识不足、城乡融合发展、依法维权意识提升）、**好词**（共建共治共享、放管服改革、基层党建）、**平易词**（钱袋子、烟火气）。
- 支持搜索、按 kind/theme 筛选、收藏、一键复制。
- 种子内容 + 手动录入 + 每日 AI 补充（走既有流水线，草稿审核入库）。

### 4.3 习语（习近平语录）

**用户已砍掉此功能**，v2 不做。原"权威源人工收录"讨论作废，不进入更新列表。

### 4.4 启发性改造（用户提供的方法论，拷问定稿）

用户指出素材"缺少启发性"，并给出方法论三步骤（观察→拆解→转化）。V2 将其落地为两部分：

**A. 话题拆解树（拆解）——并入框架栏主题树**

- 只拆 **8 大主题**（民生/生态/法治/文化/创新/经济/基层治理/青年担当），每主题拆 3~6 个细分维度。
- 示例（民生）：养老（居家/机构/社区）、就业（稳就业/新就业形态）、教育（双减/职业教育）、医疗（分级诊疗/医保改革）。
- 每个维度可挂：具体素材、规范词、好词、相关语段、相关热点。
- 数据模型：`data/topics.json`（新增）：
  ```json
  {"theme": "民生", "dimensions": [
    {"name": "养老服务", "items": ["居家社区机构相协调", "长期护理保险"], "refs": {"phrases": [...], "hotspots": [...]}}
  ]}
  ```
- 种子内容（8 主题 × 3~6 维度，由我起草）+ 手动维护。

**B. AI 辅助拆解（观察）——新录入功能**

- 表单：粘贴一段现象/新闻描述 → AI 输出结构化拆解草稿：
  ```json
  {"background": "背景", "problems": ["问题1(政策执行)", "问题2(居民习惯)", "问题3(配套措施)"],
   "measures": ["对策1", "对策2"], "angles": ["可挂靠论点1", "可挂靠论点2"], "theme": "所属主题"}
  ```
- 对应用户片段"身边小事别放过"（政策执行/居民习惯/配套措施）与"新闻热点别白刷"（背景/争议/对策）的数字化。
- 草稿审核后入库为**案例素材**（新增 type 或复用热点表，实施时定）。

**C. 素材"可用方向"字段（转化）**

- 每条素材（语段/热点/话题卡/案例）新增 `angles: []`（可用方向）字段。
- 示例：楼栋长制度素材 → `angles: ["共建共治共享", "创新社会治理", "民生服务"]`。
- 对应用户片段第三步"转化"：素材积累时先想能用在哪些方向，写答案时对号入座。
- 前端展示为可点击标签，点击可筛选出"能写这个论点"的全部素材。

**D. 拆解树与现有内容的关系**

- 拆解树维度聚合引用现有素材（按 theme 标签关联）；素材的 `angles` 与拆解树维度、表达库好词（共建共治共享等）三者可互跳。
- 种子阶段：为语段库/表达库部分种子补 `angles`；新建内容由 AI 在生成时自动输出 `angles`。

## 五、字体可调

- 设置页新增两组滑块/输入：**基础字号**（全局正文，默认 14→可调 13~18px）与**重点字号**（框架/要点/金句/标题，默认 16→可调 14~22px，加粗）。
- 重点字体与基础字体分开调节。
- 实时预览，保存写入 config.json（`font_base`、`font_emphasis`），前端 CSS 变量应用。

## 七、边界（v2 不做）

- 不做习语功能（用户已砍）。
- 不做手机端、多设备同步、账号。
- 不做自动审核入库（AI 内容仍全部进草稿）。
- 不维护机构 PDF 自动下载（用户手动下载，应用只扫描读取）。
- 拆解树只拆 8 大主题，不拆具体热点话题（v2 不扩展到第二级话题拆解）。

## 八、验收标准

1. 上线时热点库先清空，再从新抓取/挑选流程重新引入；连续抓取 3 天无旧闻（14 天窗口生效）、能挑出领导人活动等重点新闻。
2. 热点主视图显示重点提炼+要点+可背金句，摘要折叠可展开。
3. 三库点"背完了"进复习池，次日出现于今日复习清单，闪卡回忆+自评能推进/重置排期。
4. 框架 Tab 能看到 8 主题聚合 + 结构骨架 + 拆解树（每主题 3~6 维度）；表达 Tab 能按 kind/theme 筛选搜索复制。
5. 粘贴现象可 AI 拆解出背景/问题/对策/可用方向，审核入库；素材展示 angles 可点击筛选。
6. 设置页可独立调基础/重点字号并即时生效。
